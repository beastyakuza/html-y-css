MODELO DE CAJA

El modelo de caja es un concepto fundamental en CSS que describe el espacio que ocupa un elemento en la página. ej. margin, padding, border

DISPLAY

La propiedad display en CSS se utiliza para definir cómo se muestra un elemento en la página. ej. block, inline, none

FLEXBOX

Flexbox es un modelo de diseño en CSS que permite distribuir el espacio entre los elementos de una interfaz y alinear el contenido de manera eficiente. Se pueden poner en columnas o filas y en diferentes posiciones de la pantalla. Alfunas herramientas son ej. flex-wrap display: flex

MEDIDAS

En CSS, las medidas se utilizan para definir el tamaño y la posición de los elementos en una página web. En esta caso utilizamos un ejemplo de textos en rem y otros en px

PROPIEDADES

Las propiedades en CSS son las características que se pueden aplicar a los elementos HTML para controlar su apariencia y comportamiento. ej. color, font-size, background-color

SELECTORES

Los selectores en CSS son patrones utilizados para seleccionar y estilizar elementos HTML específicos en una página web. ej. id, class, element
